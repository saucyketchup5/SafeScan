SAFE SCAN FINAL WEBSITE

This package contains the complete multi-page SAFE SCAN website.

Pages:
- index.html (Home)
- about.html
- risks.html
- survey.html
- resources.html
- podcast.html
- contact.html
- help.html

All pages use the same navigation tabs. The active tab changes automatically per page.
The logo is stored at Images/logo.png.

Folder structure:
css/style.css
js/script.js
Images/logo.png
Images/fern-background.png

Open index.html in a browser to start.


Survey Results is now an in-page dropdown on every page. Selecting a Survey Results category opens that category on survey.html; on survey.html it switches sections without leaving the page.
